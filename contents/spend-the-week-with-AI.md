# Spend the week with AI






“월요일 주간 정리”를 중심으로 아래 5가지를 붙이면, **시니어처럼 AI를 ‘정보 소비’가 아니라 ‘실전 역량’으로 축적**할 수 있어.

1. `주간 AI 브리핑 (월 30분)`
- 이미 하려는 습관 유지.
- 포맷을 고정해: `뉴스 3개 + 활용사례 2개 + 바로 써볼 팁 1개`.
- 핵심은 “읽기”보다 `이번 주 내 업무에 적용할 1개`를 뽑는 것.

2. `실험 1개 룰 (주 1회, 20~40분)`
- 매주 하나만 작게 실험.
- 예: 회의록 요약, 코드 리뷰 프롬프트, 문서 초안 생성, 테스트 케이스 생성.
- 결과를 `시간 절감/품질/재사용 가능성` 3가지로 점수화.

3. `프롬프트 자산화 (주 10분)`
- 잘 먹힌 프롬프트를 버리지 말고 템플릿화.
- 구조 예시: `목표 / 입력 형식 / 제약 / 출력 형식 / 품질 기준`.
- 한 달이면 팀에서 바로 쓰는 “나만의 AI 플레이북”이 생김.

4. `실패 로그 기록 (주 10분)`
- 잘 된 것보다 안 된 케이스가 시니어를 만듦.
- 최소 3줄만 기록:
  - 무엇을 시켰나
  - 왜 실패했나
  - 다음엔 어떻게 바꿀까
- 이게 쌓이면 프롬프트 품질과 판단력이 급상승함.

5. `월말 리팩토링 (월 1회, 45분)`
- 한 달 기록을 보고 반복되는 패턴 정리.
- `버릴 습관 1개`, `자동화할 습관 1개`, `팀에 공유할 습관 1개` 선정.
- 개인 습관을 팀 영향력으로 바꾸는 단계.

바로 시작할 수 있는 최소 루틴:
- 월요일: 주간 브리핑 30분 + 실험 주제 1개 선정
- 수요일: 실험 30분
- 금요일: 결과/실패 로그 15분
- 마지막 월요일: 월간 리팩토링 45분

원하면 네 업무 스타일(개발/기획/문서/리더십)에 맞춰 **주간 템플릿(복붙용)**까지 만들어줄게.




## 정보 수집 프롬프트

```markdown
너는 시니어 AI 실무 코치다.  
입력으로 제공된 최신 AI 뉴스/활용사례/실전 팁을 바탕으로, 내 월요일 주간 정리 루틴을 실행 가능한 형태로 만들어라.

목표
- 정보 소비가 아니라 실험과 축적 중심으로 정리
- 이번 주에 바로 실행할 1개 실험을 확정
- 4주 누적 시 팀 자산으로 전환 가능한 형태로 출력

입력 데이터
- 기간: 최근 7일(필요 시 14일)
- 뉴스(최소 3개):
  1) OpenAI Codex mobile/remote update
  2) Anthropic-KPMG alliance expansion
  3) GitHub Copilot remote sessions GA
- 활용사례(최소 2개):
  1) PwC production deployments with Claude
  2) Stripe agent wallet and issuing for agents
- 실전 팁(최소 1개):
  1) Prompt engineering ops: snapshot pinning, evals, reusable prompts, caching

작업 지시
1. 위 항목을 사실 기반으로 1문장씩 요약하고, 실무 적용 가능성이 높은 순서로 우선순위를 매겨라.
2. 내 업무 관점(백엔드/아키텍처/개발생산성)에 맞춰 이번 주 실험 주제 5개를 제안하라.
3. 각 실험 주제에 대해 다음을 표로 제시하라:
- 왜 지금 해야 하는지
- 예상 효과(시간 절감, 품질 향상, 리스크 감소 중 택1 이상)
- 난이도(하/중/상)
- 소요 시간(분)
- 성공 지표(KPI 1개)
- 실패 시 학습 포인트
4. 그중 이번 주에 실행할 1개를 최종 선정하고, 3일 실행 계획(월/수/금)을 작성하라.
5. 아래 월요일 주간 정리 5가지 습관에 대해, 이번 주 버전의 실행 지침을 각각 3줄 이내로 제시하라.
- 주간 AI 브리핑(뉴스 3 + 사례 2 + 팁 1)
- 실험 1개 룰
- 프롬프트 자산화
- 실패 로그 기록
- 월말 리팩토링 준비
6. 마지막에 팀 공유용 5줄 요약을 작성하라.
- 형식: 이번 주 변화 / 우리가 시도할 것 / 기대 효과 / 리스크 / 다음 체크포인트

출력 형식
- 섹션 A: 이번 주 핵심 브리핑
- 섹션 B: 실험 후보 5개 표
- 섹션 C: 이번 주 단일 실행안(월/수/금)
- 섹션 D: 5가지 습관 실행 지침
- 섹션 E: 팀 공유 5줄 요약

제약
- 과장 금지, 수치가 없으면 추정이라고 명시
- 실행 가능한 문장만 사용
- 불필요한 배경 설명 최소화
```
